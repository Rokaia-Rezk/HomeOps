# 🏠 HomeOps – منظومة صيانة المنازل

منصة ويب لإدارة خدمات الصيانة المنزلية في **دمياط / دمياط الجديدة**، من طلب العميل لحد الفاتورة والرواتب، مع **موديل ماشين لرنينج** بيصنّف المشكلة (نوع الخدمة + الأولوية) أوتوماتيك من وصف العميل بالعامية المصرية.

🔗 **الموقع (Live Demo):** https://homeops-production-6a5b21dd.up.railway.app/#staff
> ⚠️ المشروع أكاديمي (مشروع تخرج/مناقشة). البيانات تجريبية، والدفع والرسائل (SMS/إيميل) غير مربوطة بخدمات حقيقية.

---

## ✨ المميزات

- **5 أدوار** بصلاحيات منفصلة: عميل، فني، كول سنتر، مالية، أدمن.
- **دورة طلب كاملة:** طلب ← مراجعة ← إسناد فني ← فحص وتشخيص ← إغلاق وتوقيع ← فاتورة (ضريبة 14%) ← دفع.
- **فرز ذكي (Smart Triage):** اقتراح نوع الخدمة والأولوية من وصف العميل + خانات الفورم، مع قاعدة أمان تعتبر الغاز والحريق والشرر **طوارئ** دايماً.
- **الكول سنتر:** تسجيل بلاغات، تذاكر، تصعيد، سجل مكالمات، وبحث سريع عن العملاء.
- **المالية:** فواتير، رواتب الفنيين بالعمولة، مصروفات، وتدقيق محاسبي.
- **الأدمن:** إدارة المستخدمين والصلاحيات، تشغيل/إيقاف الخدمات، سعر الساعة، وسجل تدقيق.
- **الأمان:** تشفير كلمات المرور PBKDF2-SHA256، جلسات JWT، قفل بعد 5 محاولات دخول غلط، وصلاحيات بتتشيك على السيرفر.

## 🤖 موديل الفرز الذكي (ML)

**المشكلة:** تصنيف طلب الصيانة لـ **6 فئات** (سباكة، كهرباء، تكييف وتبريد، دهانات وتشطيبات، نجارة، أجهزة منزلية) و**3 مستويات أولوية** (عادي، عاجل، طوارئ).

**الطريقة:**
1. **تطبيع النص العربي:** إزالة التشكيل والتطويل، توحيد الحروف (أ/إ/آ، ى/ي، ة/ه)، وتقليل تكرار الحروف.
2. **استخراج الخصائص:** TF-IDF على مستوى الحروف (n-grams 2–5، مناسب للعامية والأخطاء الإملائية) + على مستوى الكلمات (1–2)، مع خانات فورم منظمة (المكان، الأعراض، وقت البداية، وجود أطفال/كبار سن).
3. **الموديل:** Logistic Regression (`class_weight="balanced"`) داخل `Pipeline` – موديل للفئة وموديل للأولوية.
4. **طبقات أمان فوق الموديل:** قاعدة صريحة (غاز/حريق/شرر = طوارئ)، وSafety guard لو احتمال الطوارئ ≥ 0.30، وعتبات ثقة (فئة ≥ 0.60، أولوية ≥ 0.50) وإلا يرجع "غير مؤكد" والعميل يأكد بنفسه.

**الداتا:** مولّدة صناعياً (11,748 صف) بالعامية المصرية مع تنويع في الصياغة وأخطاء إملائية مقصودة وضوضاء واقعية في الفورم.

**النتايج** على مجموعة اختبار مكتوبة يدوياً (68 حالة، منها 24 Blind):

| النسخة | الفئة | الأولوية |
|---|---|---|
| نص فقط | 91.2% | 89.7% |
| **نص + فورم (النهائي)** | **91.2%** | **94.1%** |
| Blind (24 حالة) | 87.5% | 87.5% |

> رقم الـ Cross-Validation على الداتا الصناعية (99%+) غير واقعي لأن الداتا من قوالب، لذلك الاعتماد على مجموعة الاختبار اليدوية.

**إعادة التدريب:**
```bash
cd ml
SCALE=3 python generate_data.py && python generate_form_data.py
python make_test_form.py
python train_form.py
```

## 🚀 التشغيل محلياً

```bash
git clone https://github.com/Rokaia-Rezk/HomeOps.git
cd HomeOps/backend
python -m venv .venv
.venv\Scripts\activate          # على Linux/Mac: source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env          # على Linux/Mac: cp .env.example .env  (وعدّلي القيم)
python -m uvicorn server.main:app --reload --port 8000
```

افتحي: **http://localhost:8000**

### متغيرات البيئة (`backend/.env`)

| المتغير | الوصف |
|---|---|
| `HOMEOPS_SEED_EMAIL` | بريد حسابات الموظفين الابتدائية |
| `HOMEOPS_SEED_PASSWORD` | كلمة مرور الحسابات الابتدائية (**اختاري كلمة قوية، ومتحطيهاش على جيت**) |
| `HOMEOPS_SECRET` | مفتاح توقيع الجلسات (اختياري) |
| `HOMEOPS_DEV_OTP` | `1` = كود استعادة كلمة المرور بيظهر في لوج السيرفر (للتجربة فقط) |
| `HOMEOPS_DB` | مسار ملف قاعدة البيانات (على Railway: `/data/homeops.db`) |

## 👥 الحسابات

- **العميل:** بيسجّل حساب بنفسه من صفحة "إنشاء حساب".
- **الموظفين (فني، كول سنتر، مالية، أدمن):** حسابات بتتعمل أول تشغيل من `HOMEOPS_SEED_EMAIL` و`HOMEOPS_SEED_PASSWORD`، والأدمن يضيف موظفين من شاشة "المستخدمون والصلاحيات".

## ☁️ النشر على Railway

1. ارفعي الريبو على GitHub.
2. على [Railway](https://railway.com): **New Project ← Deploy from GitHub repo**.
3. ضيفي **Volume** على المسار `/data`.
4. اضبطي المتغيرات: `HOMEOPS_DB=/data/homeops.db`، `HOMEOPS_SEED_EMAIL`، `HOMEOPS_SEED_PASSWORD`، `HOMEOPS_SECRET`، `HOMEOPS_DEV_OTP`.
5. من Settings ← Networking اعملي **Generate Domain**.

## ⚠️ حدود معروفة

- الدفع تسجيل حالة فقط (مفيش بوابة دفع حقيقية).
- مفيش إرسال SMS/إيميل حقيقي لاستعادة كلمة المرور.
- الفواتير بضريبة 14% وغير مربوطة بمصلحة الضرائب.
- الداتا بتاعت الموديل صناعية، والتحسين المستقبلي بتجميع طلبات حقيقية.
- 3 خدمات مفعّلة (سباكة، كهرباء، دهانات) والباقي يفعّله الأدمن.
