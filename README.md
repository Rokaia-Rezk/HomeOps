# HomeOps – منظومة صيانة المنازل

```
homeops/
├── frontend/index.html   واجهة المنصة (عميل / فني / كول سنتر / مالي / أدمن)
├── backend/              FastAPI + SQLite + JWT (والسيرفر بيخدم الفرونت كمان)
│   ├── server/           الكود (main.py = كل الـ API)
│   ├── tests/            اختبارات (pytest)
│   └── .env.example      انسخيه باسم .env
└── ml/                   موديل الفرز (predictor.py + الموديلات) — السيرفر بيحمّله لوحده
```

## التشغيل (ويندوز)
```
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```
افتحي `.env` وحطي كلمة السر في `HOMEOPS_SEED_PASSWORD`، وبعدين:
```
uvicorn server.main:app --reload
```
افتحي http://127.0.0.1:8000 (على لينكس/ماك: `cp` و`source venv/bin/activate`).

## الحسابات
- **أدمن / مالي / كول سنتر / فني تجريبي**: بنفس البريد وكلمة السر اللي في `.env`، وتختاري الدور من فوق في صفحة الدخول. لو غيّرتي الباسورد في `.env` وعملتي إعادة تشغيل بيتحدّث.
- **العميل**: بيعمل حساب من الصفحة وبيتحفظ في الداتابيس ويرجع يسجل بيه.
- باقي الموظفين: الأدمن بيضيفهم من "المستخدمون والصلاحيات".
- رمز استعادة كلمة المرور بيظهر في شاشة السيرفر (التيرمنال) لحد ما نربط SMS/إيميل.

## الموديل
- بيتحمّل مع السيرفر. لو ظهر تحذير من نسخة scikit-learn، نزّلي نفس النسخة اللي دربتي بيها: `pip install scikit-learn==X.Y.Z`.
- الفرونت بينده `/api/predict` (محتاج تسجيل دخول). لو الموديل وقع الفرونت بيرجع للقواعد المبدئية.
- بيفرز 6 فئات والمنصة بتخدم 3 دلوقتي؛ الأدمن بيفتح الباقي من "الخدمات المتاحة".

## الاختبارات
```
cd backend
pytest
```

## لسه مش متعمل
- ETA (الفاتورة الإلكترونية) تجريبي بيولّد رقم وهمي.
- الصور المرفقة في الطلب بتتحسب بس (عددها)، مش بتترفع.
- لوحة الأدمن: مستخدمين وخدمات وسجل تدقيق بس، مش كل لوحات الفيجما.
- مرحلة أمر العمل عند الفني (في الطريق / وصلت...) محلية في الصفحة ومش بتتحفظ.
